
# 02 - SQL Filtering & Conditional Queries

This directory contains my MySQL exercises related to conditional queries, comparison operators, logical expressions, and pattern matching.

The examples are based on Murat Yücedağ's SQL tutorial series and adapted to MySQL where necessary.

## Contents

### 01 - WHERE and Logical Operators

**File:** [01_where_ve_mantiksal_operatorler.sql](./01_where_ve_mantiksal_operatorler.sql)

**Source Lessons:** SQL Lessons 8 and 9

Topics covered:

- Filtering records with `WHERE`
- Comparison operators: `=`, `<>`, `>`, `<`, `>=`, `<=`
- Combining conditions with `AND` and `OR`
- Matching multiple values with `IN` and `NOT IN`
- Pattern matching with `LIKE`
- Wildcards: `%` and `_`
- Range filtering with `BETWEEN`
- Handling NULL values with `IS NULL`
- Understanding logical operator precedence
- Common MySQL syntax errors

## Practice Environment

- **DBMS:** MySQL 8.x
- **Editor:** MySQL Workbench
- **Practice Database:** `kitaplık`
- **Example Table:** `Kitap`

## Learning Objectives

- Write conditional SQL queries.
- Combine multiple filtering conditions.
- Understand SQL logical operators.
- Use pattern matching to search text.
- Recognize common syntax mistakes.
- Predict the results of SQL queries.

## Study Methodology

Each topic is studied through hands-on SQL exercises.

Queries are written and tested in MySQL Workbench, followed by Turkish explanations and revision notes.

AI-assisted tools may be used to review code, explain errors, and improve documentation.

## Notes

The SQL scripts include example table definitions and sample data.

The setup statements should only be executed when needed. Repeating `INSERT` statements may create duplicate records if no appropriate uniqueness constraint exists.

SQL explanations are written in Turkish to support learning and university exam preparation.
