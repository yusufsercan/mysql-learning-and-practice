## Study Methodology

My learning process follows a practical workflow:

1. Study a topic through university notes or tutorial videos.
2. Write SQL queries independently in MySQL Workbench.
3. Execute statements and analyze the results.
4. Review errors and understand the underlying SQL rules.
5. Add Turkish explanations and revision notes to the SQL files.
6. Organize and document completed exercises on GitHub.

AI-assisted tools may be used for technical review, formatting, explanation refinement, and SQL dialect adaptation.

The objective is to understand the queries I write rather than simply collect working examples.
