# 🗄️ MySQL Learning & Practice

This repository contains SQL queries, database exercises, and practical examples developed during my university studies and personal learning sessions.

> ⚠️ **Note:** This repository represents my ongoing learning journey. The primary goal is to strengthen my SQL fundamentals, understand relational databases, and build a solid foundation for future software development and cybersecurity studies.

---

## 📂 Repository Structure

- **01-SQL-Basics:** Fundamental SQL statements, including `SELECT`, `INSERT`, `UPDATE`, and `DELETE`.
- **02-Filtering-and-Sorting:** Filtering records with `WHERE`, comparison operators, and sorting with `ORDER BY`.
- **03-Aggregate-Functions:** Aggregate functions such as `COUNT`, `SUM`, `AVG`, `MIN`, and `MAX`, along with `GROUP BY` and `HAVING`.
- **04-Joins-and-Relationships:** Combining data from multiple tables using SQL joins and understanding relational database concepts.
- **05-Practical-Challenges:** SQL exercises, query-writing practice, and problem-solving challenges.

*Topics and folders will be expanded as I progress through my studies.*
