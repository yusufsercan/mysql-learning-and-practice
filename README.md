# MySQL Learning & Practice

This repository documents my ongoing learning and hands-on practice with MySQL, relational databases, and database design as a Software Engineering student.

It brings together university coursework, SQL tutorials, practical exercises, and personal study notes. My goal is to develop a solid understanding of relational database concepts, write reliable SQL queries, and improve my ability to solve database problems independently.

The repository is maintained as an **educational learning archive**, not a production application.

---

## Repository Structure

The repository is organized into topic-based modules, progressing from fundamental SQL operations to relational modeling and exam-oriented exercises.

| Module | Description |
|---|---|
| [01-SQL-Basics](./01-SQL-Basics) | Database creation, DDL and DML operations, data types, constraints, and table modifications. |
| [02-Filtering-and-Sorting](./02-Filtering-and-Sorting) | Conditional queries, logical operators, `WHERE`, `DISTINCT`, `ORDER BY`, `LIKE`, and data modification. |
| [03-Aggregate-Functions](./03-Aggregate-Functions) | Aggregate functions, `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `GROUP BY`, and `HAVING`. |
| [04-Joins-and-Relationships](./04-Joins-and-Relationships) | Table relationships, `INNER JOIN`, outer joins, `CROSS JOIN`, and SQL set operations. |
| [05-ER-Modeling-and-Relational-Schema](./05-ER-Modeling-and-Relational-Schema) | E-R diagrams, Chen notation, relationship cardinality, relational schema conversion, and normalization. |
| [06-SQL-Exam-Practice](./06-SQL-Exam-Practice) | Exam-style SQL questions, multi-table queries, worked solutions, result tables, and problem-solving strategies. |

Each module contains SQL scripts, study notes, or supporting documentation focused on its respective topics.

## Current Learning Focus

My current focus is applying previously studied SQL and database concepts through practical exercises and university examination preparation.

The main areas I am reinforcing include:

- Writing multi-table SQL queries using correct JOIN conditions.
- Understanding primary-key and foreign-key relationships.
- Using filtering, grouping, aggregation, and sorting together.
- Predicting query results before executing SQL statements.
- Converting E-R diagrams into relational schemas.
- Identifying normalization problems and improving table structures.
- Practicing subqueries and more advanced SQL problem-solving.

The emphasis is on understanding **why a query works and how its result is produced**, rather than memorizing SQL syntax.

---

## Study Methodology

My learning process follows a structured, practice-oriented workflow:

1. Study a topic using university materials, technical resources, or SQL tutorials.
2. Understand the underlying concepts and examine relevant examples.
3. Write SQL queries independently using MySQL Workbench.
4. Execute the queries and compare the results with my expectations.
5. Analyze errors, unexpected outputs, and alternative solutions.
6. Document important concepts, SQL syntax, common mistakes, and practical observations in Turkish.
7. Organize completed exercises and revision notes into topic-based GitHub directories.

Some study materials and explanations are reviewed with AI-assisted tools for technical clarification, error analysis, and documentation refinement.

The purpose of this workflow is to build a deeper understanding of SQL through repeated implementation and review.

## SQL Exam Practice

The [06-SQL-Exam-Practice](./06-SQL-Exam-Practice) module focuses specifically on applying SQL concepts to realistic examination questions.

It uses a fictional fitness center database called **FitZone**, containing members, instructors, classes, and class registrations.

This module includes:

- A reusable MySQL practice database.
- SQL questions covering filtering, JOIN operations, grouping, and aggregation.
- Step-by-step explanations of how to approach each question.
- Worked SQL solutions and expected result tables.
- Notes on common mistakes and important SQL behaviors.

The practice exercises are intended to support independent problem-solving. I review the examples, attempt similar questions without looking at the solutions, and compare the results to identify areas that need improvement.
